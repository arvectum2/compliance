## Принципы реализации

1. Data Platform не содержит специализированных правил 152-ФЗ.
2. Compliance Core не зависит от SaaS и платежных провайдеров.
3. Результаты имеют код правила, версию, свидетельство и уровень уверенности.
4. Проверка извне не объявляется подтверждением полного соответствия.
5. Изменения на сайтах только по подтверждённым правам и с одобрением.
6. Серверный обход ограничен и устойчив к SSRF/внутренним адресам.
7. SDK/API/CLI доступны внутренним продуктам без SaaS-подписки.

## AC-00 acceptance gate

- Существуют репозитории GitHub, GitVerse и локальная рабочая копия.
- Workflow выполняется успешно и синхронизирует SHA main и refs.
- LaunchAgent установлен, проверен fast-forward и защита грязного дерева.
- Далее: специфицировать rule schema, finding/evidence schema, API
  и зависимости от Data Platform перед началом разработки движка.
