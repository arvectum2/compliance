# Feature 001 — foundation and offline static compliance scan
Spec Kit 1.2.4 | Статус: реализуется | 2026-11-05

## Пользовательские сценарии
1. Разработчик передаёт HTML и исходный URL, получает машинно-читаемые *технические наблюдения*, пригодные для CI без сетевого доступа.
2. Владелец, явно подтвердивший право на сканирование URL, может запросить ограниченный статический GET; отсутствие разрешения не вызывает запросов.
3. Инженер Арвектум использует правило/доказательство через Python API, а SaaS может переиспользовать его без переписывания логики.

## Требования
- FR-001: пакет Python 3.11+ с CLI и публичными dataclass-моделями, JSON schema_version.
- FR-002: сканер обнаруживает формы (метод, action, список полей), ссылки на документы и сигналы consent, без хранения введённых значений.
- FR-003: находки ограничены эвристическими проверками: отсутствие видимой ссылки на политику на странице с формой, внешний action, непроверенное наличие согласия. Статус review, а не нарушение закона.
- FR-004: каждая находка имеет rule_id, rule_version, severity, evidence selector/fragment, source_url; результаты воспроизводимы.
- FR-005: HTTP CLI без явного --authorized не выполняет запрос; лимиты размера/времени, запрет непубличных URL; браузерное выполнение скриптов по умолчанию отключено.
- FR-006: адаптер использует публичные модели AcquisitionEngine и AcquisitionRequest из Data Platform; no vendor forks.
- FR-007: тесты полностью автономны; нет внешней сети или DNS в обычном pytest.
- FR-008: результат содержит limitations, включая невозможность проверить операторскую документацию, серверную локализацию данных, согласия на стороне backend.

## Не входит в Feature 001
- Правовая оценка фактического соответствия, автоматическое заключение «нарушение».
- Проход авторизованных страниц, выполнение JS, запись HAR/клиентских cookies.
- SaaS, биллинг, создание PR в сторонних проектах.

## Критерии приёмки
- AT-001: положительные/отрицательные HTML-фикстуры проходят локально и в CI.
- AT-002: без --authorized сетевой вызов отклоняется до приобретения данных.
- AT-003: localhost/private и credential URLs отвергаются; redirect на чужой origin блокируется.
- AT-004: JSON сериализуется, сортировка находок стабильна, секреты и значения форм не выводятся.
- AT-005: вызов модуля Python отдельно от CLI работает без SaaS/API.
