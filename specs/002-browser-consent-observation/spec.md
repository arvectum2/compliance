# Feature 002 — браузерные сценарии согласия и запросов
Статус: PLANNED | Spec Kit 1.2.4 | 2026-11-05

## Пользовательские истории
- Владелец подтверждает владение доменом. Система сравнивает cookies и
  HTTP запросы до взаимодействия с баннером и после выбора отказа/согласия.
- Владелец видит временную шкалу и доказательства по каждому выявленному
  стороннему endpoint, но не получает голословное заключение «нарушение 152-ФЗ».

## FR
- FR-002-01: отдельный изолированный Playwright worker без возможности
  сетевого доступа во внутреннюю сеть; validation each redirect/subresource.
- FR-002-02: ввод ограничен подтверждёнными доменами, max pages/bytes/time;
  не отправлять формы и не нажимать неидентифицированные кнопки.
- FR-002-03: baseline, reject, accept запускаются в новых браузерных контекстах,
  только по явно распознанным контролам и правилам конкретного сайта.
- FR-002-04: HAR-подобный результат хранит домен, тип, время, признаки cookies;
  не сохраняет значения cookies, тела запросов, токены, PII.
- FR-002-05: неопределённый consent UI => inconclusive, не автоматическая ошибка.
- FR-002-06: результаты содержат версию сценария, rule_version, браузер,
  время и source hash; сохранение до изменения должно быть воспроизводимым.

## Acceptance
- AT-002-01: fixture pages с network before/after в контролируемом браузере.
- AT-002-02: SSRF сценарии localhost/169.254.169.254/private/redirect/subresources
  заблокированы на сетевом слое; DNS rebinding проверен.
- AT-002-03: нет cookie values/PII в артефактах.
- AT-002-04: ложные consent controls не приводят к submit/POST.
